# 站点准入记录

更新日期：2026-07-14。

MySound-Pro 只注册无需登录、会员、私有 Cookie、Token 或签名的公开来源。公开可访问不等于永久可用；每个站点仍需通过搜索、详情、章节、播放、稳定性和使用政策审计。

| 来源 | 状态 | 结论 |
|---|---|---|
| Project Gutenberg 音频（Gutendex 目录） | 启用 | 公开搜索，`media_type=Sound`，Gutenberg 直接 MP3，无鉴权；线上 smoke 与随机样本通过。 |
| LibriVox | 启用 | 官方 released API，公版志愿者录音，无鉴权；线上 smoke 与随机样本通过。 |
| 听书网 | 启用 | 公开 HTML 搜索、详情、章节和播放页，无登录或签名；媒体地址来自静态 script。 |
| 博看有声 | 启用 | 公开租户目录和分页章节 API，无用户凭据；章节提供 AAC/M4A 直链。 |
| 云图有声 | 启用 | 公开租户目录和章节 API，无用户凭据；章节提供 MP3 直链与时长。 |
| 69 听书 | 隔离 | 详情与播放页公开，但当前搜索页要求验证码；插件不绕过验证码，因此不注册。 |
| Internet Archive | 隔离 | API 契约测试通过，但本次准入环境连续连接超时；稳定性未达首发要求。 |
| i275 / 56 听书候选域名 | 拒绝 | 当前为默认建站页，不能确认有效公开目录。 |
| YSTS | 隔离 | 详情请求出现 444/超时，未达到稳定性要求。 |

隔离 Parser 没有 `@AudioSourceMetadata`，不会进入 KSP 自动注册表。恢复前必须重新完成线上 smoke、100 本抽样和政策复核。
